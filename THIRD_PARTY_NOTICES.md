## External SiYuan SDK

The `siyuan@1.2.9` SDK from `siyuan-note/petal` is used for development, types and
host integration. It remains external to the production bundle; SiYuan supplies
the runtime. No SDK implementation or type files are distributed in the plugin
package. No license declaration is supplied by the inspected SDK package, and
this notice does not assign it a license.

Other packages are development/test/build tools recorded in `package-lock.json`.
