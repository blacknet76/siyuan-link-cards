# Link Cards

Turn ordinary URLs into rich, passive Link Cards with a description, preview image and site favicon.
Insert supported YouTube videos as native SiYuan embeds using the same dialog.
The interface is available in English and German.

![Link Cards overview in light theme](docs/screenshots/link-cards-light.png)

## Features

- Passive Link Cards from ordinary URLs.
- Preview images, descriptions and site favicons.
- Native YouTube embeds from supported video URLs.
- Slash actions and selected-URL prefill.
- Local preview assets where possible.
- English and German interface.

## Usage

- `/card` or `/bookmark` → passive **Bookmark Card**.
- `/embed` → native **YouTube Embed**.

Switch between Bookmark Card and Embed in the same insertion dialog.

## Compatibility

Requires **SiYuan 3.8.3+**.
